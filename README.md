# Simulador de Órgão VR — Yamaha B-205

Órgão de dois teclados em realidade mista (WebXR) para Meta Quest 2/3. O órgão é posicionado sobre a mesa
onde você pousar as mãos (rastreamento de mãos ou controles). Abra no navegador do Quest:

https://asmarinho84.github.io/orgao-vr/

## Créditos
Modelo 3D "Yamaha Organ B-205" por gethiox (Blend Swap), licença Creative Commons Attribution 3.0
